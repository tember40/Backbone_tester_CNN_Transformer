## 선택적 후속 제안과 미확인 범위

- 다른 OS/GPU, VS Code 실제 화면, 완전한 새 의존성/데이터 다운로드, 논문 규모 성능·속도 비교는 미검증이다. 이 검증이 모든 환경을 보장하지는 않는다.
- 선택적으로 validation 기준의 전용 비교 보고 흐름과 실제 여러 seed 실험을 추가할 수 있으나, 이번에는 현재 CLI의 test 정렬/반복 평가 한계를 정확히 설명하는 범위로 한정했다.
- PVT의 학습/분류 경로에서 사용하지 않는 `freeze_patch_emb`·`reset_classifier` 보조 API는 별도 정비 후보다. 현재 공개 실습은 이 API를 사용하지 않는다. 모델 구조나 인터페이스를 넓히는 후속 작업과 분리한다.
- 전 장에 새 그림·애니메이션을 넣거나 새로운 프레임워크·계정·서버 학습을 도입하는 작업은 필요하지 않아 수행하지 않았다.
