## 검증 기록

### 2026-10-20 · 1~3장 보완 묶음

- `python -m unittest discover -s tests`: 56개 통과. 작은 CPU 학습 및 체크포인트 재개 테스트 포함(실제 CIFAR-10 전 모델 성능 비교가 아님).
- `node --test tests/test_foundations_web.cjs`: 6개 통과. 실제 페이지 컨트롤러를 최소 DOM 어댑터에서 실행해 초기화·타이머·종료 사유 확인. 레이아웃 검증을 대신하지 않음.
- JS 문법 검사 및 `git diff --check` 통과.
- Python과 JS의 AND 첫 epoch: 오차 `[-1,0,0,1]`, 최종 w≈`[0.1,0.1]`, b=0. Python float32와 JS double의 작은 반올림 차이는 허용.
- 3장 수치 예제: h=0.4621171573, p=0.6135163044, L=0.4885484392, 갱신 후 L=0.4531941133. `test_single_hidden_neuron_chain_rule_matches_autograd`가 수식과 PyTorch 미분 대조.
- 실제 브라우저: 기본 PC 폭 1280, 태블릿 820, 모바일 390. 1~3장 수식·추적표·표 컨테이너의 화면 밖 넘침 없음. 모바일 수식은 세로 순서로 개선. 3장 100 epoch L=0.4749, 초기화 시 epoch=0/L=0.6893로 복원. 자동 실행 중 수동 버튼 비활성 확인.
- 메인의 문제 항목 5개 선택 시 Hero 본문 top=402.3125px로 일정. 시작 버튼 → 1장 scrollY=0, 코드 초기 강조 9줄 유지. 추적표 초기화 확인. 확인한 탭의 콘솔 오류/경고 없음.
- 출처: Stanford CS229 퍼셉트론 강의 노트의 수렴 조건·학습률 배율, PyTorch BCEWithLogitsLoss 문서, Nature 원 논문 초록, MIT Press 출판 메타데이터. 원 그림은 복제하지 않음.
- 미리보기: Python 서버 8765는 프로세스 수신 상태와 달리 응답이 지연됨. 대체 Node 기본 HTTP 서버의 `docs/` 전용 localhost:8766에서 화면 확인. 이 임시 미리보기는 제품 의존성이 아님.
- Git 배포: 이 묶음 커밋·배포 확인 전. 전체 목표 완료 아님.
