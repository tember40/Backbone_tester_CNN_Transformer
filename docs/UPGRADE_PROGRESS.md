## 검증 기록

### 2026-10-20 · 1~3장 보완 묶음

- `python -m unittest discover -s tests`: 56개 통과. 작은 CPU 학습 및 체크포인트 재개 테스트 포함(실제 CIFAR-10 전 모델 성능 비교가 아님).
- `node --test tests/test_foundations_web.cjs`: 6개 통과. 실제 페이지 컨트롤러를 최소 DOM 어댑터에서 실행해 초기화·타이머·종료 사유 확인. 레이아웃 검증을 대신하지 않음.
- JS 문법 검사 및 `git diff --check` 통과.
- Python과 JS의 AND 첫 epoch: 오차 `[-1,0,0,1]`, 최종 w≈`[0.1,0.1]`, b=0. Python float32와 JS double의 작은 반올림 차이는 허용.
- 3장 수치 예제: h=0.4621171573, p=0.6135163044, L=0.4885484392, 갱신 후 L=0.4531941133. `test_single_hidden_neuron_chain_rule_matches_autograd`가 수식과 PyTorch 미분 대조.
- 실제 브라우저: 기본 PC 폭 1280, 태블릿 820, 모바일 390. 1~3장 수식·추적표·표 컨테이너의 화면 밖 넘침 없음. 모바일 수식은 세로 순서로 개선. 3장 100 epoch L=0.4749, 초기화 시 epoch=0/L=0.6893로 복원. 자동 실행 중 수동 버튼 비활성 확인.
- 메인의 문제 항목 5개 선택 시 Hero 본문 top=402.3125px로 일정. 시작 버튼 → 1장 scrollY=0, 코드 초기 강조 9줄 유지. 추적표 초기화 확인. 확인한 탭의 콘솔 오류/경고 없음.
- 출처: Stanford CS229 퍼셉트론 강의 노트의 수렴 조건·학습률 배율, PyTorch BCEWithLogitsLoss 문서, Nature 원 논문 초록, MIT Press 출판 메타데이터. 원 그림은 복제하지 않음.
- 미리보기: Python 서버 8765는 프로세스 수신 상태와 달리 응답이 지연됨. 대체 Node 기본 HTTP 서버의 `docs/` 전용 localhost:8766에서 화면 확인. 이 임시 미리보기는 제품 의존성이 아님.
- Git 배포: `edea262`를 main에 푸시. 공개 `/docs/chapters/01-perceptron.html`에서 새 계산 모듈 로드와 첫 단계 갱신 확인, 2장 새 탐색 안내·3장 역전파 예제 표시 확인. 확인한 공개 탭의 오류/경고 없음. 전체 목표 완료 아님.

### 2026-10-20 · 4~6장 보완 묶음

- 이전 목표 턴은 1~3장 구현·테스트·배포로 실제 진전이 있었다. 이번 턴도 새 계산/시각화 오류 수정 및 독립 검산을 수행했다.
- `python -m unittest discover -s tests`: 61개 통과. 새 5개는 RGB Conv2d, padding shape, Max/AvgPool 역전파, 실제 AlexNet 수용영역, 수집 시 원 값·혼합 train/eval·예외 경로 복구를 검증.
- `node --test tests/test_foundations_web.cjs tests/test_cnn_web.cjs`: 14개 통과. 새 8개는 행렬 계산, stride>kernel coverage, 실제 페이지 컨트롤러의 shape 오류·색 척도·수용영역을 검증. 후속 문구/용어장 변경 뒤 static-site 24개·CNN JS 8개 재확인. Ruff는 환경에 없어 실행하지 않았으며 설치하지 않음.
- 실제 브라우저: PC 1280·태블릿 820·모바일 390에서 4~6장의 실험·수식·표 컨테이너가 화면 밖으로 넘치지 않음. 모바일 RGB 합산 표와 풀링 빗금 그림을 직접 확인했고 6.6 제목의 단일 글자 줄바꿈을 짧은 제목으로 수정. 폰트 크기 변경 없음.
- 수치: N=5/K=7/P=0은 계산 불가 안내. N=8/K=2/S=3에서 실제 사용 36칸·미사용 28칸. 정렬된 경계는 Max/Avg 차이 0/16, 한 칸 이동은 4/16·최대 차이 0.375. AlexNet 전체 8개 공간 연산의 r=[3,4,12,14,22,30,38,42], j 최종 8. 입력을 넘는 영역은 잘라 표시한다고 설명.
- 4~6장 진행 표시 1/3·2/3·3/3 유지. 4장 모바일 용어장 열기/닫기 및 새 Translation 용어 표시 확인. 확인한 탭의 콘솔 오류/경고 없음. 미리보기 서버는 기존 Node 프로세스 21724의 수신 상태를 확인하고 재사용(재시작하지 않음).
- 출처 확인: LeCun 공저 연구자 사이트의 1998 서지, Zeiler/Fergus arXiv 초록 및 Springer ECCV 2014 서지·초록, PyTorch Conv2d/MaxPool2d 문서, Distill 수용영역 원문. Zeiler 개인 사이트 PDF 조회는 실패했으므로 원문 전체를 읽었다고 주장하지 않음. 외부 그림은 복제하지 않음.
- Git 반영·공개 배포 확인 전. 전체 목표는 미완료이며 나머지 게이트는 그대로 남음.

## 다음 작업

4~6장 묶음을 커밋·배포 확인한 뒤 7~9장 본문·모델·계산 실험을 검토한다. 이후 10~16장, 17~18장, 설치·문서·전체 회귀 검증 순서로 진행한다. 전체 목표는 위 모든 게이트가 충족될 때까지 유지한다.

배포 최종 점검에서는 사용자 정의 Actions의 `path: docs`와 저장소 루트 레거시 리다이렉트가 만드는 주소 배치를 대조한다. 두 배포 경로의 `/docs/` 제공 방식이 다르면 동일한 정적 주소 배치로 맞추고 검증한다. GitHub 설정이나 호스팅 제공자는 임의로 변경하지 않는다.
