# Backbone Lab 전공 교재 템플릿

## 광운대학교 시각 체계

웹 교재의 색상과 배경은 광운대학교 발표 자료의 슬라이드 마스터를 기준으로 합니다.

- 대표 버건디: `#7C192D` — 제목, 버튼, 진행 상태, 결정경계
- 기본 배경: `#F7F6F3` — 넓은 면의 따뜻한 회백색
- 보조 배경: `#FBF4EF` — 학습 목표와 강조 영역
- 모노라인: `#C6BFAA` — 얇은 기하학 배경선과 구분선
- 보조 강조: `#FBAE40` — 경고, 오답 수정, 현재 학습 단계
- 본문 서체: `맑은 고딕`을 우선하고, 코드에는 고정폭 서체를 사용합니다.

모노라인은 표지를 포함한 장 도입부에만 낮은 대비로 사용합니다. 본문과 실습 영역에는 장식선을 겹치지 않아 읽기 흐름을 방해하지 않도록 합니다.

각 장은 `templates/chapter-template.html`을 복사해 작성합니다. 디자인보다 읽는 순서가 먼저 보이도록 다음 원칙을 유지합니다.

1. 장 첫 화면에는 중심 질문과 학습 목표만 둡니다.
2. 절 번호는 `장.절` 형식으로 표기합니다.
3. 본문은 **개념 → 계산 예제 → 실제 구현 → 실습 → 정리와 문제** 순서로 구성합니다.
4. 논문은 별도 발표 카드가 아니라 아이디어의 역사적 근거로 짧게 인용합니다.
5. 수식에는 번호 또는 역할을 붙이고, 바로 아래 코드에서 같은 연산을 찾게 합니다.
6. 실습은 실행 전에 예상 질문을 제시하고, 실행 후 관찰할 값을 명시합니다.
7. 장 끝에는 핵심 정리, 핵심 용어, 연습문제를 둡니다.

## 공통 구성 요소

- `.learning-objectives`: 장의 학습 목표
- `.callout`: 정의와 보충 설명
- `.callout-question`: 실행 전 생각해 볼 문제
- `.callout-tip`: 수식과 코드의 연결
- `.equation-card`: 수식 또는 계산 흐름
- `.lab-panel`: 브라우저 대화형 실습
- `.code-study`: 실제 코드와 줄별 해설
- `.chapter-summary-box`: 장 끝의 핵심 정리와 용어

본문 스타일은 `assets/css/site.css` 하나를 공유합니다. 장별 JavaScript는 `assets/js/`에 분리하며, 콘텐츠에 필요한 `id`만 HTML에 둡니다.
