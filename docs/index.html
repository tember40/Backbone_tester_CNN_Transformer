HOW TO LEARN

모든 장은 같은 순서로 학습합니다

새로운 모델이 등장한 이유부터 실제 코드와 실험 결과까지 한 흐름으로 연결합니다.

  1. 01문제 발견

    이전 모델이 해결하지 못한 문제를 확인합니다.

  2. 02논문 아이디어

    핵심 기여를 쉬운 그림과 짧은 수식으로 정리합니다.

  3. 03실제 코드

    프로젝트에서 실행되는 코드와 줄별 해설을 읽습니다.

  4. 04직접 실험

    값을 바꾸며 중간 계산과 결과 변화를 관찰합니다.

  5. 05결과 해석

    정확도 하나가 아니라 그래프와 실패 사례를 읽습니다.
