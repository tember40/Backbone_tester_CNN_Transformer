자료 구성

설명, 수식, 코드, 실험을 한 흐름으로 읽습니다

각 장은 같은 학습 구조를 사용하므로 모델이 복잡해져도 읽는 방법은 달라지지 않습니다.

  1. 01학습 목표

    이 장에서 설명하고 계산할 수 있어야 할 내용을 먼저 확인합니다.

  2. 02개념과 수식

    모델의 필요성과 핵심 연산을 작은 단위로 나누어 읽습니다.

  3. 03구현

    수식이 실제 프로젝트 코드에서 어떻게 표현되는지 연결합니다.

  4. 04실습

    값을 바꾸고 학습 단계를 재생하며 모델의 동작을 관찰합니다.

  5. 05정리와 문제

    핵심 용어를 정리하고 연습문제로 이해도를 확인합니다.
