제4장합성곱과 필터

사진의 모든 픽셀을 한꺼번에 연결하지 않고도 모서리와 무늬를 찾을 수 있을까요? 작은 필터가 이미지를 이동하며 같은 규칙을 반복 적용하는 과정을 숫자 하나씩 따라갑니다.

학습 목표

  • 국소 연결과 가중치 공유가 필요한 이유를 설명할 수 있습니다.
  • 이미지 패치와 필터의 원소별 곱을 계산할 수 있습니다.
  • 커널 크기, 보폭, 패딩으로 출력 크기를 구할 수 있습니다.
  • 서로 다른 필터가 만드는 특징맵을 비교할 수 있습니다.

4.2 합성곱을 만드는 세 가지 생각

합성곱층은 작은 영역을 보고, 같은 필터를 이동하며, 여러 필터의 응답을 채널로 쌓습니다.

  1. 01
    국소 연결

    한 출력 값은 입력 전체가 아니라 커널 크기만큼의 작은 영역만 봅니다.

    무엇을 보는가
  2. 02
    가중치 공유

    하나의 필터를 모든 위치에서 재사용하므로 위치마다 별도 가중치를 둘 필요가 없습니다.

    어떻게 반복하는가
  3. 03
    다중 필터

    서로 다른 필터가 세로선, 가로선, 질감처럼 서로 다른 특징맵을 만듭니다.

정의 4.1 · 가중치 공유

필터가 왼쪽 위에 있든 오른쪽 아래에 있든 같은 가중치를 사용하는 규칙입니다. 덕분에 모델은 같은 모양을 위치와 무관하게 탐지할 수 있고 파라미터 수도 줄어듭니다.

수학의 합성곱과 딥러닝의 표기

엄밀한 수학적 합성곱은 커널을 뒤집지만, PyTorch의 `Conv2d`를 비롯한 딥러닝 구현은 커널을 그대로 미는 상호상관을 계산합니다. 필터가 학습되기 때문에 실무에서는 이를 관례적으로 합성곱이라 부릅니다.

4.4

공간 크기

4.4 필터가 몇 번 놓이는지 계산하는 법

입력 크기 N, 커널 K, 패딩 P, 보폭 S가 정해지면 한 축의 출력 크기는 아래 식으로 결정됩니다.

출력 크기⌊(N + 2P − K) / S⌋ + 1
입력32 × 32
→
출력32 × 32

⌊(32 + 2×1 − 3) / 1⌋ + 1 = 32

3×3 필터와 패딩 1, 보폭 1은 가로·세로 크기를 유지합니다.
패딩가장자리 밖에 값을 덧댐

가장자리 픽셀도 중심 픽셀처럼 여러 번 계산에 참여하게 합니다.

보폭필터가 이동하는 간격

보폭이 커지면 계산 위치와 출력 해상도가 함께 줄어듭니다.

def trace_single_channel_convolution(image, kernel, stride=1, padding=0):
    image_tensor = torch.as_tensor(image, dtype=torch.float32)
    kernel_tensor = torch.as_tensor(kernel, dtype=torch.float32)
    padded = functional.pad(
        image_tensor, (padding, padding, padding, padding)
    )
    kernel_height, kernel_width = kernel_tensor.shape
    output_height = (padded.shape[0] - kernel_height) // stride + 1
    output_width = (padded.shape[1] - kernel_width) // stride + 1
    output = torch.empty((output_height, output_width), dtype=torch.float32)
    steps = []
    for output_row in range(output_height):
        for output_column in range(output_width):
            image_row = output_row * stride
            image_column = output_column * stride
            patch = padded[
                image_row:image_row + kernel_height,
                image_column:image_column + kernel_width,
            ]
            products = patch * kernel_tensor
            value = products.sum()
            output[output_row, output_column] = value
실제 모델에서는 어떻게 계산할까?

`torch.nn.Conv2d`가 여러 입력 채널과 여러 필터를 한 번에 효율적으로 계산합니다. 이 함수는 같은 원리를 한 채널씩 펼쳐 보여 주기 위한 학습용 구현입니다.
