제10장 · 채널마다 중요도를 다시 정하다SENet

ResNet은 특징을 더 쉽게 전달하도록 연결을 바꾸었습니다. SENet의 질문은 다릅니다. 이미 계산한 특징맵에서 어떤 채널을 더 볼 것인가? 공간 전체를 평균 내고, 채널별 가중치를 만든 뒤, 원래 특징맵에 곱합니다. 이 장에서는 그 세 단계가 실제 코드의 어느 줄에 있는지 확인합니다.

학습 목표

  • Squeeze가 특징맵을 채널별 값 하나로 요약하는 과정을 계산할 수 있습니다.
  • Excitation과 scale이 채널별 반응을 조절하는 방식을 설명할 수 있습니다.
  • 축소 비율 reduction이 중간 차원과 파라미터 수에 미치는 영향을 구할 수 있습니다.
  • SE 모듈이 이 저장소의 ResNet 블록 어디에 들어가는지 코드로 찾을 수 있습니다.
10.1

논문의 질문

10.1 채널을 모두 똑같이 볼까?

Jie Hu · Li Shen · Gang Sun2017 공개CVPR 2018

Squeeze-and-Excitation Networks

합성곱은 공간 패턴과 채널 정보를 함께 처리하지만, 기존 블록은 출력 채널 사이의 관계를 명시적으로 조절하지 않습니다. SE 블록은 입력 특징에서 채널별 신호를 추출하고, 그 신호에 따라 같은 이미지의 채널 반응을 다시 가중합니다. 독립된 분류 모델이라기보다 기존 CNN 블록에 붙이는 연산 단위로 이해하는 편이 정확합니다.

원 논문 보기 ↗

논문은 이를 squeeze → excitation → scale의 순서로 설명합니다. 먼저 공간 축을 줄여 채널의 전역 정보를 모읍니다. 이어 채널 간 의존성을 이용해 각 채널의 가중치를 구하고, 원래 특징맵에 채널별로 곱합니다. 공간 위치마다 다른 마스크를 만드는 과정은 아닙니다.

10.2 채널마다 값 하나로 요약하기

특징맵이 [C, H, W]라면 global average pooling은 각 채널의 H×W 값을 평균 내 [C, 1, 1]을 만듭니다. 아래 2×2 예시에서 값을 바꾸고 채널별 평균을 확인하세요.

zc = (1 / HW) Σi,j Uc,i,j→[C, H, W] → [C, 1, 1]

값을 바꾸면 현재 채널의 평균과 오른쪽 요약 벡터가 함께 바뀝니다.

이 단계는 어디에서 반응했는지 세부 위치를 압축합니다. 어떤 채널이 상대적으로 크게 활성화됐는지를 전역적으로 보여주지만, 평균 하나만으로 분류 근거를 완벽하게 설명할 수는 없습니다.

10.3

실습 10.2 · 채널 재보정

10.3 같은 채널 전체에 한 가중치

요약 벡터 z는 작은 두 층의 MLP를 거쳐 채널별 가중치 s가 됩니다. 첫 선형층은 채널 수를 줄이고, ReLU 뒤 두 번째 선형층이 다시 C개로 늘립니다. 마지막 Sigmoid 출력은 0과 1 사이입니다.

s = sigmoid(W₂ · ReLU(W₁z))→Ũc,i,j = sc · Uc,i,j

실습 10.3 · 계산량 읽기

10.4 축소 비율이 하는 일

이 저장소의 SELayer는 channel // reduction을 중간 차원으로 사용합니다. 두 Linear 층은 모두 bias=False이므로 SE 부분의 파라미터는 2 × C × (C // r)개입니다.

r을 키우면 중간 차원과 추가 파라미터가 줄어듭니다. 대신 채널 관계를 표현하는 중간 공간도 작아집니다. SE가 가볍게 추가될 수 있다는 말이 모델 전체가 작아진다는 뜻은 아닙니다. 실제 절감·성능 효과는 기준 모델과 실험 조건을 함께 비교해야 합니다.

10.5

ResNet에 끼워 넣기

10.5 덧셈 전에 채널을 조절한다

이 저장소의 BasicBlock은 두 번째 합성곱과 BatchNorm 뒤에 SE를 적용하고, 그 다음 shortcut을 더한 뒤 ReLU를 통과시킵니다. 따라서 SE 가중치는 주 경로의 출력에 곱해지며, 우회 경로 residual에는 직접 곱하지 않습니다.

Conv → BN → ReLUConv → BNSE: squeeze → excitation → scale+ shortcutReLU

Bottleneck에서도 세 번째 합성곱과 BatchNorm 다음에 SE가 들어갑니다. 원 논문은 SE 단위를 여러 CNN에 붙일 수 있음을 제안하지만, 여기서 실습하는 구현은 SE-ResNet 계열입니다. 이름이 SENet이라고 해서 모든 층 구조가 논문의 수상 모델과 동일한 것은 아닙니다.

10.7

실제 프로젝트 코드

10.7 네 줄로 읽는 SE 연산

아래는 backbone/SeNet.py의 SELayer.forward입니다. 해설을 선택하면 해당 줄이 강조됩니다. self.fc는 생성자에서 Linear → ReLU → Linear → Sigmoid로 정의합니다.

backbone/SeNet.py · SELayer.forward
def forward(self, x):
    b, c, _, _ = x.size()
    y = self.avg_pool(x).view(b, c)
    y = self.fc(y).view(b, c, 1, 1)
    return x * y.expand_as(x)

expand_as(x)는 가중치의 [B,C,1,1] 모양을 원래 특징맵 [B,C,H,W]에 맞춰 확장합니다. 이 함수는 픽셀마다 별도의 새 가중치를 학습하지 않습니다. 이어 BasicBlock.forward의 out = self.bn2(out) 다음 out = self.se(out)이 실행되고, 그 후 out += residual이 일어납니다.

10장 핵심 정리

  • Squeeze는 각 채널의 공간 값을 평균 내 전역 요약을 만듭니다.
  • Excitation은 채널 간 관계를 반영한 가중치 벡터를 만듭니다.
  • Scale은 채널마다 같은 가중치를 모든 공간 위치에 곱합니다.
  • 이 구현에서는 SE를 잔차 주 경로에 적용한 뒤 shortcut을 더합니다.
Squeeze

Excitation

Scale
원래 특징맵에 채널별 가중치 적용
