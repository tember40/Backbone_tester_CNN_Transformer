제8장VGG

AlexNet이 깊은 CNN의 가능성을 보여주었다면, VGG는 구조를 단순하게 통일한 뒤 깊이를 체계적으로 늘려 보았습니다. 작은 3×3 합성곱을 반복할 때 수용영역, 특징맵 크기, 파라미터가 어떻게 달라지는지 실제 구현으로 확인합니다.

학습 목표

  • 3×3 합성곱을 연속으로 쌓는 이유와 조건부 파라미터 절약을 설명할 수 있습니다.
  • VGG11·13·16·19의 블록별 합성곱 수와 공통점을 구분할 수 있습니다.
  • 원 논문 구조와 이 프로젝트의 CIFAR-10 변형을 혼동하지 않습니다.
  • 가중치 메모리와 학습 전체 메모리를 구분해 추정할 수 있습니다.
8.1

논문의 질문

8.1 깊이를 늘리면 이미지 인식이 좋아질까?

Karen Simonyan · Andrew Zisserman2014ICLR 2015

Very Deep Convolutional Networks for Large-Scale Image Recognition

VGG는 거의 모든 합성곱을 3×3, 보폭 1로 통일하고 풀링 뒤 채널을 늘리며, 가중치가 있는 층을 11개에서 19개까지 바꾸어 깊이의 효과를 조사했습니다. 여러 변수를 동시에 바꾸기보다 구조를 일정하게 유지한 비교 실험이라는 점이 중요합니다.

원 논문 보기 ↗

VGG16이라는 이름의 16은 합성곱 13층과 완전연결 3층을 합친 가중치 층 수입니다. ReLU와 풀링을 더한 모든 연산 수가 16이라는 뜻은 아닙니다.

예를 들어 3×3 두 층의 이론적 수용영역은 5×5입니다. 입력·중간·출력 채널을 모두 64로 고정하면 3×3 두 층은 73,856개, 5×5 한 층은 102,464개의 파라미터가 필요합니다. 두 층 사이에 ReLU가 들어가므로 같은 연산을 단순 대체한 것은 아닙니다.

8.4

원 논문과 프로젝트 구현

8.4 입력 크기가 달라지면 마지막 특징도 달라진다

항목원 논문 VGG16이 프로젝트 VGG16
입력224×224 RGB32×32 RGB (CIFAR-10)
3×3 합성곱13층13층
2×2 풀링5회5회
마지막 특징512×7×7512×1×1
분류 범주1,000개10개
파라미터약 1억 3,800만 개33,638,218개

다섯 번의 풀링은 공간의 가로·세로를 각각 절반으로 줄입니다. 32 → 16 → 8 → 4 → 2 → 1이므로 마지막 특징은 512×1×1입니다. 구현의 AdaptiveAvgPool2d((1, 1))도 분류기로 넘길 크기를 1×1로 고정합니다. 분류기 첫 선형층의 입력은 512개이므로 원 논문보다 훨씬 작습니다. 따라서 여기서 학습한 가중치를 논문 모델의 가중치로 볼 수 없습니다.

현재 코드의 사전학습 옵션에 주의하세요

backbone/VGG.py의 pretrained=True는 가중치 초기화를 건너뛰지만, 가중치를 내려받는 부분은 주석 처리되어 있습니다. 사전학습 모델을 실제로 불러오는 기능이 아닙니다.

8.5

실제 프로젝트 코드

8.5 짧은 설정 목록이 반복 구조를 만든다

아래는 backbone/VGG.py의 make_layers 핵심 부분입니다. 오른쪽 해설을 선택하면 관련 코드 줄이 강조됩니다.

backbone/VGG.py
def make_layers(cfg, batch_norm=False):
    layers = []
    in_channels = 3
    for v in cfg:
        if v == 'M':
            layers += [nn.MaxPool2d(kernel_size=2, stride=2)]
        else:
            conv2d = nn.Conv2d(in_channels, v, kernel_size=3, padding=1)
            if batch_norm:
                layers += [conv2d, nn.BatchNorm2d(v), nn.ReLU(True)]
            else:
                layers += [conv2d, nn.ReLU(True)]
            in_channels = v
    return nn.Sequential(*layers)

VGG16의 설정 D는 블록별 합성곱 횟수가 2–2–3–3–3입니다. 분류기에는 512 → 4096 → 4096 → 10의 선형층 세 개가 있습니다. 배치 정규화 버전은 기본 모델과 층 구성 및 파라미터 수가 달라지므로 이 장의 수치 비교에서 제외했습니다.

8.6

실습 8.3 · 메모리 읽기

8.6 깊은 모델은 어디에 메모리를 쓸까?

모델과 배치 크기를 바꿔 float32 가중치 하나와 첫 특징맵 하나의 크기를 따로 비교하세요. 학습 전체 GPU 메모리와는 다릅니다.

모델 가중치 한 벌—배치 크기에 직접 비례하지 않음
첫 합성곱 출력 한 개—배치 × 64 × 32 × 32

—

VGG16의 분류기만 18,923,530개 파라미터로, 전체 33,638,218개의 절반 이상입니다. 그러나 실제 학습에서 메모리 부족이 생기면 가중치만 볼 수 없습니다. 여러 층의 활성화, 역전파 기울기, 옵티마이저 상태도 함께 차지합니다.

8.7 단순한 반복 구조의 장점과 비용

8장 핵심 정리

  • VGG는 3×3 합성곱을 반복해 깊이의 효과를 체계적으로 비교했습니다.
  • 3×3 두 층은 이론적으로 5×5 수용영역을 가지며, 중간 비선형성이 추가됩니다.
  • VGG16은 합성곱 13층과 완전연결 3층으로 이뤄집니다.
  • 같은 블록 구성이라도 입력과 분류 범주가 달라지면 마지막 특징과 파라미터가 달라집니다.
