제3장다층 퍼셉트론

직선 하나로 풀 수 없는 문제를 여러 뉴런은 어떻게 해결할까요? 은닉층이 입력을 새로운 표현으로 바꾸고, 오차가 각 연결로 돌아가는 과정을 단계별로 확인합니다.

학습 목표

  • 입력층, 은닉층, 출력층의 역할을 구분할 수 있습니다.
  • 가중합과 활성화를 따라 순전파 값을 계산할 수 있습니다.
  • 비선형 활성화 함수가 필요한 이유를 설명할 수 있습니다.
  • 손실, 기울기, 가중치 갱신의 연결 관계를 추적할 수 있습니다.
3.1

역사적 배경

3.1 오차를 뒤로 보내 내부 표현을 학습하다

David E. Rumelhart · Geoffrey E. Hinton · Ronald J. Williams1986Nature 323

Learning Representations by Back-Propagating Errors

출력 오차를 여러 층의 연결에 나누어 전달하며 가중치를 수정하는 학습 절차를 설명했습니다. 은닉 뉴런은 사람이 정답을 직접 지정하지 않은 중간 특징을 학습할 수 있습니다.

문제

은닉층의 정답은 알 수 없다

출력의 정답은 있어도 각 은닉 뉴런이 무엇을 출력해야 하는지는 주어지지 않습니다.

아이디어

미분으로 책임을 나눈다

최종 오차에 각 연결이 미친 영향을 연쇄법칙으로 계산합니다.

의미

표현 자체를 학습한다

은닉층이 문제 해결에 필요한 중간 특징을 데이터에서 구성합니다.

용어를 구분해 읽기

역전파는 기울기를 계산하는 방법이고, 경사하강법이나 Adam은 계산된 기울기로 파라미터를 실제 수정하는 최적화 방법입니다.

3.4 예측 오차가 가중치까지 돌아오는 길

학습 한 번은 순전파, 손실 계산, 역전파, 파라미터 갱신의 네 단계로 이루어집니다.

  1. 01
    순전파

    입력에서 출력 방향으로 계산해 예측 확률을 구합니다.

    logits = model(features)
  2. 02
    손실 계산

    예측과 정답의 차이를 하나의 숫자로 요약합니다.

    loss = criterion(logits, targets)
  3. 03
    역전파

    연쇄법칙으로 각 파라미터가 손실에 미친 영향을 계산합니다.

    loss.backward()
  4. 04
    가중치 갱신

    손실이 감소하는 방향으로 optimizer가 파라미터를 이동합니다.

    optimizer.step()

3.5 실제 PyTorch 모델의 층별 값 읽기

TinyMLP의 forward_trace는 은닉층 전후와 출력 확률을 모두 반환하므로 학습 과정의 내부 값을 직접 확인할 수 있습니다.

cifar10_lab/foundations.py
class TinyMLP(nn.Module):
    def __init__(self, hidden_features=4):
        super().__init__()
        self.hidden = nn.Linear(2, hidden_features)
        self.activation = nn.Tanh()
        self.output = nn.Linear(hidden_features, 1)

    def forward_trace(self, features):
        hidden_linear = self.hidden(features)
        hidden = self.activation(hidden_linear)
        logits = self.output(hidden).squeeze(-1)
        probabilities = torch.sigmoid(logits)
        return {
            "hidden_linear": hidden_linear,
            "hidden": hidden,
            "logits": logits,
            "probabilities": probabilities,
        }

    def forward(self, features):
        return self.forward_trace(features)["logits"]
왜 학습에서는 확률보다 logit을 사용할까?

`BCEWithLogitsLoss`는 sigmoid와 이진 교차엔트로피를 수치적으로 안정적인 한 연산으로 결합합니다.
