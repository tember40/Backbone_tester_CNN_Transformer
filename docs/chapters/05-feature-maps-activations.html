제5장특징맵과 활성화

필터가 만든 숫자 배열은 다음 층에서 어떻게 사용될까요? 여러 특징맵이 채널로 쌓이고, 활성화 함수가 남길 신호를 선택하는 과정을 내부 값으로 확인합니다.

학습 목표

  • CNN 텐서의 N, C, H, W 차원을 읽을 수 있습니다.
  • 필터 수와 출력 특징맵 채널 수의 관계를 설명할 수 있습니다.
  • ReLU 적용 전후의 값과 0의 비율을 비교할 수 있습니다.
  • 코드로 중간 특징맵을 수집하고 해석할 수 있습니다.

특징맵은 완성된 의미 지도가 아니다

초기 층은 선이나 색 변화처럼 비교적 단순한 패턴에 반응하지만, 한 채널을 사람이 붙인 개념 하나와 항상 동일시할 수는 없습니다. 여러 채널과 공간 위치를 함께 해석해야 합니다.

5.3

채널의 생성

5.3 필터 하나가 특징맵 하나를 만든다

입력 채널 전체를 보는 필터 묶음 하나가 출력 채널 하나를 만듭니다. 따라서 출력 채널 수는 입력 채널 수가 아니라 필터 묶음의 개수로 정해집니다.

입력3 × 32 × 32

RGB 채널 3개

×
필터 묶음64 × 3 × 3 × 3

출력 64개 × 입력 3개 × 3×3

→
출력64 × 32 × 32

특징맵 64개

학습 파라미터(3 × 3 × 3 + 편향 1) × 64 = 1,792개

공간 위치마다 새 가중치를 만들지 않고 같은 필터를 공유합니다.

정의 5.1 · 출력 채널

서로 다른 필터 묶음이 만든 특징맵의 개수입니다. `nn.Conv2d(3, 64, 3)`의 64가 출력 채널 수이며, 각 필터는 RGB 세 채널을 모두 읽습니다.

ReLU는 음수 응답을 0으로 바꾸고 양수 응답은 그대로 유지합니다.

z < 00으로 차단

현재 필터와 반대 방향이거나 약한 반응을 다음 층에 전달하지 않습니다.

z > 0값을 그대로 전달

양수 구간의 기울기가 1이어서 깊은 네트워크의 학습을 단순하게 만듭니다.

0이 많으면 항상 좋은가?

희소한 표현은 불필요한 반응을 줄일 수 있지만, 모든 입력에서 한 뉴런의 출력이 계속 0이면 기울기도 전달되지 않는 ‘죽은 ReLU’가 될 수 있습니다.

5.5 특징맵을 숫자로 요약하는 실제 코드

특징맵을 그림으로만 보지 않고 shape, 최솟값, 최댓값, 평균, 양수와 0의 비율을 함께 기록하면 층별 활성화 상태를 비교할 수 있습니다.

cifar10_lab/cnn_visualization.py
def summarize_activations(features):
    """Return compact statistics for a feature-map tensor before or after activation."""
    feature_tensor = torch.as_tensor(features, dtype=torch.float32)
    if feature_tensor.ndim not in (3, 4):
        raise ValueError("features must have shape [C, H, W] or [N, C, H, W].")
    return {
        "shape": tuple(feature_tensor.shape),
        "minimum": float(feature_tensor.min().item()),
        "maximum": float(feature_tensor.max().item()),
        "mean": float(feature_tensor.mean().item()),
        "positive_ratio": float((feature_tensor > 0).float().mean().item()),
        "zero_ratio": float((feature_tensor == 0).float().mean().item()),
    }
그림과 통계를 함께 보는 이유

특징맵 그림은 공간 패턴을 보여 주고, 통계는 채널 전체의 포화·희소성·값 범위를 수치로 비교하게 해 줍니다. 둘 중 하나만 보면 중요한 이상을 놓칠 수 있습니다.

  • PyTorch의 CNN 텐서는 일반적으로 [N, C, H, W] 순서입니다.
