2.2

핵심 개념

2.2 수식을 직선으로 읽는 법

입력이 두 개일 때 가중합이 0이 되는 점들을 모으면 하나의 직선이 됩니다.

분류 점수

z = w₁x₁ + w₂x₂ + b

→
결정경계

w₁x₁ + w₂x₂ + b = 0

  1. 1
    가중치는 직선의 방향을 정합니다.

    w₁과 w₂의 비율이 바뀌면 경계가 회전합니다.

  2. 2
    편향은 직선의 위치를 정합니다.

    가중치를 고정하고 b만 바꾸면 경계가 평행 이동합니다.

  3. 3
    직선의 양쪽이 서로 다른 예측 영역입니다.

    z가 0 이상인 쪽은 1, 0보다 작은 쪽은 0으로 분류합니다.

AND한 점만 1

(1, 1)을 나머지 세 점과 직선으로 분리할 수 있습니다.

OR한 점만 0

(0, 0)을 나머지 세 점과 직선으로 분리할 수 있습니다.

XOR같은 값이 대각선에 위치

어느 직선을 그어도 적어도 한 점은 반대쪽에 남습니다.

정의 2.1 · 선형 분리 가능

서로 다른 두 클래스를 하나의 직선, 평면 또는 고차원 초평면의 서로 반대쪽에 놓을 수 있는 상태입니다.

같은 직선과 같은 예측은 다를 수 있습니다

w₂가 0이 아니면 경계는 x₂=−(w₁/w₂)x₁−b/w₂로 쓸 수 있습니다. 예를 들어 w=(1,1), b=−1.5이면 x₂=−x₁+1.5입니다. 두 가중치와 편향에 같은 양수를 곱해도 z의 부호가 같으므로 경계와 예측은 같습니다. 같은 음수를 곱하면 경계는 같아도 양쪽 예측 영역은 뒤집힙니다. 정확히 z=0인 점은 이 자료의 규칙에 따라 계속 1입니다.

실험의 각도 θ는 직선 자체의 기울기가 아니라 직선에 수직인 법선 벡터 w=(cos θ, sin θ)의 각도입니다. θ=0°이면 w=(1,0)이므로 경계는 수직선 x₁=−b입니다. w=(0,0)인 경우에는 경계의 방향을 정할 수 없어 일반적인 직선식으로 해석하지 않습니다. 아래 각도 실험은 길이 1인 벡터를 사용하므로 이 퇴화한 경우는 발생하지 않습니다.

2.3

증명 따라가기

2.3 XOR에서 생기는 네 부등식

네 점을 모두 맞히는 가중치가 있다고 가정하고, 그 가정이 스스로 모순을 만드는지 확인합니다.

출력이 1인 두 점

(1, 0) → w₁ + b ≥ 0

(0, 1) → w₂ + b ≥ 0

두 식을 더하면 w₁ + w₂ + 2b ≥ 0입니다.

출력이 0인 두 점

(0, 0) → b < 0

(1, 1) → w₁ + w₂ + b < 0

b < 0이므로 첫 두 식은 w₁ + w₂ + b > 0을 요구합니다.
모순 w₁ + w₂ + b가 동시에 0보다 커야 하고 작아야 합니다.

따라서 네 점을 모두 맞히는 단일 직선은 존재하지 않습니다.

위 모순은 네 점을 모두 맞힐 수 없다는 상한을 줍니다. 한편 w=(1,1), b=−0.5를 대입하면 아래처럼 실제로 세 점을 맞힐 수 있습니다. 네 점에 같은 비중을 주는 정확도에서 75%가 달성되므로, 상한과 달성 가능한 값이 일치합니다.

2.4 하나의 경계를 코드로 평가하기

프로젝트의 실제 함수는 각 점의 점수와 예측을 계산한 뒤 정답 여부와 전체 정확도를 함께 반환합니다.

cifar10_lab/foundations.py
def evaluate_linear_boundary(features, targets, weights, bias):
    """Return predictions, correctness, and accuracy for one line."""
    feature_tensor = torch.as_tensor(features, dtype=torch.float32)
    target_tensor = torch.as_tensor(targets, dtype=torch.long)
    weight_tensor = torch.as_tensor(weights, dtype=torch.float32)

    scores = feature_tensor @ weight_tensor + float(bias)
    predictions = (scores >= 0).to(torch.long)
    correct = predictions.eq(target_tensor)
    accuracy = correct.float().mean().item()
    return predictions, correct, accuracy
코드와 수식 연결하기

`feature_tensor @ weight_tensor + bias`가 모든 점에 대해 w₁x₁ + w₂x₂ + b를 계산합니다. 아래 실험의 각도는 가중치 방향을, 위치는 편향을 바꿉니다.
