제7장AlexNet

깊은 합성곱 신경망이 대규모 이미지 인식의 중심으로 올라선 전환점을 살펴봅니다. 논문의 아이디어를 외우는 데서 그치지 않고, CIFAR-10용 구현의 각 층을 지나며 shape과 파라미터가 어떻게 달라지는지 추적합니다.

학습 목표

  • AlexNet이 주목받은 기술적·데이터적 배경을 설명할 수 있습니다.
  • 합성곱부와 분류기의 역할을 shape 변화로 구분할 수 있습니다.
  • 원 논문 구조와 CIFAR-10 변형의 차이를 설명할 수 있습니다.
  • Dropout이 학습 중 뉴런을 다루는 방식을 해석할 수 있습니다.
7.1

전환점이 된 논문

7.1 더 큰 데이터와 계산으로 깊은 CNN을 학습하다

Alex Krizhevsky · Ilya Sutskever · Geoffrey E. Hinton2012NeurIPS

ImageNet Classification with Deep Convolutional Neural Networks

대규모 ImageNet 데이터에서 깊은 CNN을 두 GPU로 학습하고, 2012년 분류 대회에서 기존 방법보다 큰 폭으로 낮은 오류를 기록했습니다. 네트워크 구조뿐 아니라 데이터, 연산 장치, 최적화 기법이 함께 성능을 만든 사례입니다.

논문에 보고된 학습 파라미터

AlexNet이 CNN을 처음 만든 것은 아니다

합성곱 신경망의 계보는 훨씬 앞선 연구로 이어집니다. AlexNet의 의미는 기존 CNN 아이디어를 대규모 데이터와 GPU 계산에 결합해 일반 이미지 인식에서 압도적인 결과를 보였다는 데 있습니다.

7.5

실제 순전파 코드

7.5 특징 추출부와 분류기를 연결하기

프로젝트의 `forward`는 네 단계로 읽을 수 있습니다. 합성곱 특징을 만들고, 크기를 고정하고, 한 줄로 펼친 뒤 완전연결 분류기에 전달합니다.

backbone/AlexNet.py
def forward(self, x):
    x = self.features(x)
    x = self.avgpool(x)
    x = torch.flatten(x, 1)
    x = self.classifier(x)
    return x
출력은 확률이 아니라 logits

마지막 선형층의 열 개 값은 정규화되지 않은 점수입니다. 학습 손실인 `CrossEntropyLoss`가 내부에서 필요한 확률 변환을 함께 처리하므로 모델 끝에 softmax를 중복해서 넣지 않습니다.

실습 7.2 · Dropout

7.6 학습할 때마다 다른 경로를 사용하기

Dropout 확률을 바꾸고 다시 표본화해 어떤 뉴런이 남는지 확인하세요. 실제 AlexNet 분류기는 두 은닉층에서 `p=0.5`를 사용합니다.

학습 모드`model.train()`

확률 p로 뉴런을 끄고 남은 값을 1/(1−p)배 보정합니다.

평가 모드`model.eval()`

모든 뉴런을 사용하며 무작위 마스크를 적용하지 않습니다.

Dropout을 합성곱층에도 항상 써야 할까?

공간적으로 가중치를 공유하는 합성곱층은 완전연결층보다 파라미터가 적습니다. AlexNet은 파라미터가 집중된 완전연결층에 Dropout을 적용했고, 이후 구조에서는 정규화·데이터 증강·확률적 깊이 등 다양한 방법이 함께 사용됩니다.

7장 핵심 정리

  • AlexNet의 성과는 깊은 CNN, ImageNet 데이터, GPU 계산, 학습 기법이 결합된 결과입니다.
  • 합성곱부는 공간 특징을 만들고 분류기는 펼친 특징으로 클래스 점수를 계산합니다.
  • CIFAR-10 변형은 32×32 입력을 보존하기 위해 첫 필터와 보폭을 줄입니다.
  • Dropout은 학습 중 일부 뉴런을 무작위로 꺼 완전연결층의 과적합을 줄입니다.
